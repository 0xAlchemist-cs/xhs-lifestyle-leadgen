# xhs-lifestyle-leadgen

小红书「路人号 + 精准获客」运营 Skill。

**一句话**：把一个普通人的生活账号，运营成目标赛道精准用户的引流入口——生活内容建真人感，少量高意向内容抓搜索流量和咨询线索，评论区与私信自然承接，全程零营销号观感。

## 它解决什么问题

做小红书获客的人通常掉进两个坑：
- 做成垂直攻略号 → 有流量但没人设，转化靠硬导流，违规风险高
- 做成纯生活号 → 有真人感但抓不到高意向用户

这个 skill 是第三条路：**人设是真的，流量入口是设计出来的。**

## 核心方法（实战验证）

- **A池/B池三级内容池** + 动态发布节奏（生活 60–75% / 轻旅游 / 高意向 ≤15%，L3 永不连发）
- **发布决策 10 问**：每次"下一篇"先判断账号当前状态，再给推荐，确认后出稿
- **真实数据调研**：站内搜索数据拉取 → 评论/点赞比 → 评论≥100 过滤 → 钩子分布 → 求助帖清点 → 对标筛选器（低粉高赞/近3月/可复制封面）
- **答题式评论区获客**：在真实提问帖下用真实经历答题，每周 ≤3 条，零引导——和机构托完全反着来
- **素人差异化四张牌**：真经历敢写缺点 / 提问者→回答者叙事 / 公开可查记录 / 视角空位
- **三条红线**：不编造经历、不做批量营销、真人感永远优先于涨粉效率

## 安装

```bash
npx skills add <你的用户名>/xhs-lifestyle-leadgen
```

或直接把本仓库复制到你的 agent skills 目录（`~/.agents/skills/` 或 `~/.claude/skills/`）：

```bash
git clone https://github.com/0xAlchemist-cs/xhs-lifestyle-leadgen.git ~/.agents/skills/xhs-lifestyle-leadgen
```

兼容任何支持 Agent Skills 协议的环境（ZCode / Claude Code / Codex / Cursor 等）。

## 使用

对 agent 说：

- "帮我运营一个小红书账号，不想做营销号但要精准客户" → 走完整流程（定位 → 调研 → 内容池 → 排期）
- "给我下一篇" → 执行 10 问决策，给推荐等你确认
- "研究一下XX赛道的爆款" → 走调研工作流
- "分析数据" → 复盘八问 + 更新内容池

## 边界（诚实声明）

- 不教批量营销、群发私信、站外导流——那些是限流封号项，也与路人号模式对立
- 内容真实性依赖使用者提供真实素材；skill 会强制标注 `[需补真实素材]` 而不是编造
- 站内数据拉取依赖浏览器自动化工具（如 browser-act）和用户自己的登录态，不绕过任何平台风控
