# 内容池与发布决策规则

## A池：生活内容（占 60–75%）

作用：真人感、主页防伪、连续生活轨迹。**数据差不是失败，这类内容的价值在主页观感，不在单篇数据。**

选题主干（按人设定制）：
- 吃饭/下厨/外卖/探店
- 兴趣爱好（用户真实有的：手工/观影/追星/游戏……营销号绝不会发的那些）
- 工作/通勤/周中情绪/攒假期
- 朋友社交/周末/城市探索
- 消费红黑榜/换季整理/随手拍
- 情绪碎片/相册翻旧照/天气

**埋伏笔位**：A 池里保留 10–15% 的"旅游前置帖"——攒年假、购物车里全是装备、深夜刷目的地视频、屏保换成雪山。让后续旅游内容出现得毫不突兀。

**生活帖写作铁律**：细节必须来自用户当天的真实碎片（让用户口述一两句，agent 组装），**绝不替用户编造场景**。"周三买了杯奶茶坐在路边喝完"这种没发生过的细节一眼假。图片用手机实拍原图，不统一调色。

## B池：旅行内容三级

| 级别 | 承载 | 视角 | 频率约束 |
|---|---|---|---|
| L1 轻旅游 | 兴趣和情绪 | "突然想去""又开始看机票" | 无硬限制，保持克制 |
| L2 旅游分享 | 信息/搜索流量 | 整理研究视角，可结构化 | 距上次 ≥2 篇 |
| L3 高意向 | 精准获客 | 具体问题/价格/选择/避坑 | **永不连续，两次间隔 ≥3 篇非 L3** |

L3 选题模板（围绕"准备期用户最想知道的问题"）：
- 忘带什么最绝望 / 千万别忘带的东西
- X 天到底花多少钱（三档预算）
- 包车 vs 拼车 vs 自驾怎么选 / 报价差在哪
- 小环线 vs 大环线怎么选
- 第一次去最容易忽略的 N 件事
- 帮你看行程（评论投稿互动型）

**禁用词**（营销腔）：必看 / 保姆级 / 超详细 / 纯干货 / 赶紧收藏 / 姐妹们冲 / 宝子闭眼入。标题要像真人随口说的："研究了一晚上XX路线，发现第一次去真的不用这么贪心"。

## "给我下一篇"时的 10 问决策

1. 最近 10 篇的类型分布？
2. 生活/旅游比例对照目标区间？
3. 是否连续出现旅游内容（≥2 篇连续 → 强制回归生活）？
4. 最近两篇是否过于相似？
5. 哪类内容数据最好（有数据时）？
6. 主页前 9 格旅游密度是否超标（≥4 格 → 补生活）？
7. 当前适合发旅游吗（L3 间隔 ≥3 篇、L2 ≥2 篇）？
8. 若发旅游，是 L1/L2/L3 哪级（依据账号阶段 + 距假期时间 + 哪级缺位）？
9. 当前最值得获取哪类用户（决策期→L3 问题型；观望期→L2；泛兴趣→L1）？
10. 是否需要隐藏旧帖（见下）？

输出格式（先推荐，确认后再写正文）：
```
【推荐下一篇】类型
【推荐理由】基于上述问题的简答
【具体选题】
【标题方向】
【预计吸引的人群】
【主页观感预览】发完后的 A/B 分布
```

## 隐藏机制（工具，不是动作）

- 默认**不隐藏**旧帖；删除笔记会降账号等级，隐藏（仅自己可见）不会
- 仅当旧帖：无持续搜索价值 + 主页旅游密度超标 + 人设冲突时建议隐藏
- **仍在带流量的帖不藏**（持续产生收藏/评论的入口帖是资产）
- L3 新帖发布后，紧邻下一篇必须是 A 池生活帖稀释

## 发布时间

强搜索型内容选晚 8–10 点（目标人群刷屏高峰）。新笔记有约 24h 保底曝光，前 2 小时数据决定追加——发布后用户自己别反复刷看。
